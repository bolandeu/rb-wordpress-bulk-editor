
 Usage: wp-bulk export [OPTIONS]

 Экспорт всего контента сайта в файлы.

 Находит все типы контента и экспортирует их в отдельные HTML файлы.
 Создает CSV индекс.

 Example: wp-bulk export --output ./exported_content

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --domain         -d      <str>   WordPress domain                                                │
│ --username       -u      <str>   WordPress username                                              │
│ --password       -p      <str>   WordPress Application Password                                  │
│ --env-file               <file>  Путь к .env файлу                                               │
│ --output         -o      <path>  Папка для экспорта контента [default: exported_content]         │
│ --concurrency    -c      <int>   Количество параллельных загрузок [default: 10]                  │
│ --include-media                  Включить экспорт метаданных медиа                               │
│ --verbose        -v              Подробные логи                                                  │
│ --help                           Show this message and exit.                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
