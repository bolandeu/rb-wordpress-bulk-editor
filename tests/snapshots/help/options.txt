
 Usage: wp-bulk options [OPTIONS]

 Управление настройками сайта WordPress.

 Без --fetch: обновление WordPress из Excel
 С --fetch: выгрузка настроек из WordPress в Excel

 Запись настроек на сайт и перезапись существующего xlsx откатить нельзя:
 сначала доступен --dry-run, затем спрашивается подтверждение, а под
 --non-interactive требуется явный --confirm.

 Exit-коды: 0 — успех, 2 — аргументы/файл или отсутствующий --confirm,
 3 — нет credentials,
 5 — недоступен WordPress, 1 — непредвиденная ошибка.

 Example: wp-bulk options --fetch --dry-run

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --file             -f      FILE  Путь к Excel файлу                                              │
│ --env-file                 FILE  Путь к .env файлу (по умолчанию .env)                           │
│ --fetch                          Получить настройки из WordPress в Excel (вместо загрузки)       │
│ --dry-run          -d            Показать что будет отправлено, без отправки                     │
│ --confirm                        Подтвердить опасную операцию без вопроса.                       │
│ --non-interactive                Никогда не спрашивать; вместо вопроса — ошибка.                 │
│ --json                           Машиночитаемый JSON-вывод.                                      │
│ --quiet                          Только существенный вывод.                                      │
│ --help                           Show this message and exit.                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
