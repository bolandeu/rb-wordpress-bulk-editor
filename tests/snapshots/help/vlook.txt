
 Usage: wp-bulk vlook [OPTIONS]

 Привязка файлов к строкам Excel по ID (VLOOKUP по файловой системе).

 Ищет файлы {id}.ext в папке и записывает имя файла в колонку Excel.


 Режимы:
   content - {id}.html в content/ -> content_path (по умолчанию)
   media   - {id}.<картинка> в media/ -> img_path
   both    - content + media одновременно
   custom  - --folder + --column, любые файлы

 Example: wp-bulk vlook --mode media

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --mode     -m      TEXT  Режим: content, media, both, custom [default: content]                  │
│ --file     -f      PATH  Excel файл (по умолчанию export.xlsx)                                   │
│ --sheet    -s      TEXT  Конкретный лист (по умолчанию все контентные)                           │
│ --folder           PATH  Папка для поиска (режим custom)                                         │
│ --column           TEXT  Колонка для записи (режим custom)                                       │
│ --verbose  -v            Подробные логи                                                          │
│ --help                   Show this message and exit.                                             │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
