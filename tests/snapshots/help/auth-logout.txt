
 Usage: wp-bulk auth logout [OPTIONS]

 Удалить доступ сайта из OS keychain. Отсутствующий доступ — не ошибка.

 Example: wp-bulk auth logout --provider wp:example.com

╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ *  --provider        <str>  Сайт: wp:<домен>. [required]                                         │
│    --json                   Машиночитаемый JSON-вывод.                                           │
│    --quiet                  Только существенный вывод.                                           │
│    --help                   Show this message and exit.                                          │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
